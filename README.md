# Voice transcription with speaker verification

An experimental, local speech-to-text pipeline that transcribes speech only
when the captured voice is similar to an enrolled speaker embedding.

The pipeline combines:

1. streaming microphone capture;
2. ONNX voice-activity detection (VAD);
3. ECAPA-TDNN speaker embeddings and cosine-similarity verification;
4. local Whisper.cpp transcription through `pywhispercpp`.

This is a prototype, not an authentication system. Speaker-verification scores
can vary with microphones, background noise, illness, distance, and replayed
audio. Do not use the result to grant access or make consequential identity
decisions.

## Privacy

Microphone audio, transcripts, and speaker embeddings can be sensitive. The
application is designed to run locally, but you are responsible for obtaining
consent before recording anyone and for following applicable privacy and
recording laws.

The generated `baseline.npy` file is a biometric-derived identifier. It and all
sample audio are excluded from Git. Store them as carefully as you would other
sensitive personal data.

## Requirements

- Python 3.10 or newer
- a working microphone supported by `sounddevice`
- a Silero-compatible VAD ONNX model matching the inputs expected by
  `VADProcessor`
- a speaker-embedding ONNX model generated by `export_to_onnx.py`

Create an environment and install the runtime dependencies:

```bash
python -m venv .venv
```

Windows:

```bat
.venv\Scripts\activate
python -m pip install -r requirements.txt
```

Linux or macOS:

```bash
source .venv/bin/activate
python -m pip install -r requirements.txt
```

## Prepare the speaker model

Model-export dependencies are kept separate from the smaller runtime:

```bash
python -m pip install -r requirements-model-export.txt
python export_to_onnx.py
```

The exporter downloads SpeechBrain’s
[`speechbrain/spkrec-ecapa-voxceleb`](https://huggingface.co/speechbrain/spkrec-ecapa-voxceleb)
model into a local cache and writes `speaker_model.onnx`. The upstream model is
Apache-2.0 licensed and is not bundled in this repository.

Place a compatible VAD model at `silero_vad.onnx`, or update the paths in
`config.json`.

## Enroll a speaker

Record a clear, consented voice sample and generate the local baseline:

```bash
python generate_baseline.py path/to/consented-sample.wav
```

Alternatively, install the optional UI dependencies and start the local Gradio
enrollment interface:

```bash
python -m pip install -r requirements-ui.txt
python ui.py
```

The interface binds to `127.0.0.1` and does not intentionally expose itself to
other computers.

## Run

Review `config.json`, then start the microphone loop:

```bash
python main.py
```

`pywhispercpp` downloads its configured Whisper model on first use when it is
not already available locally. The default is `tiny.en`.

## Development checks

```bash
python -m unittest discover -s tests -v
python -m compileall -q .
```

## Project status

This repository is an early proof of concept. It does not yet include robust
audio-device selection, model download automation for VAD, packaging, threshold
calibration across conditions, or an end-to-end test fixture.
